# Zeinab — My Life Is a Map

A personal landing page built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — visual design and responsive layout
- `script.js` — interactive map pins + small interactions
- `assets/` — personal photos
- `resume.pdf` — downloadable resume

## GitHub Pages
1. Create a GitHub repository.
2. Upload everything in this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from branch.
4. Select the `main` branch and `/ (root)`.
5. Save. GitHub will publish the site.

No build step or framework is required.
